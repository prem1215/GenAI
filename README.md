# GenAI
A comprehensive collection of GenAI experiments, research papers, and implementation scripts covering LLMs

## Projects

### 1. Trip Planner
A smart road trip planner that helps you plan safe and comfortable breaks during long drives. Built as a Model Context Protocol (MCP) server, it seamlessly integrates with AI assistants to provide intelligent trip planning and break recommendations.

### 2. MyFoccus Chrome Extension
Goal of this project is to analyze and summarize pages in Chrome automatically and score their relevance to personal learning goals. It requires on-device AI; if unavailable, analysis is disabled.

### 3. Terms and Conditions Assistant
A conversational chatbot that helps users ask questions about the terms and conditions of apps or agreements. Get answers related to T&Cs through a friendly chat interface.
